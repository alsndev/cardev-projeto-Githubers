# \## Problema de Negócio

# 

# Uma associação regional de artesãos e pequenos produtores de Caraguatatuba comercializa produtos em feiras físicas. Durante a alta temporada, a associação enfrenta dificuldades para controlar o estoque de produtos exclusivos e perde oportunidades de venda porque não oferece reservas antecipadas aos turistas.

# 

# Durante a baixa temporada, também não existe uma vitrine digital para divulgar o catálogo de produtos. Além disso, o controle atual realizado em cadernos de papel pode causar divergências nas vendas e atrasos nos repasses aos artesãos.

# 

# \## Solução Proposta

# 

# Desenvolver uma aplicação web que funcione como uma vitrine digital dos produtos da associação, permitindo consultar o catálogo, cadastrar produtos, controlar o estoque e realizar reservas antecipadas.

# 

# A solução busca centralizar as informações dos produtos e facilitar o gerenciamento do estoque, reduzindo problemas causados pelo controle manual em papel.

# 

# \## Requisitos Funcionais

# 

# \* \*\*RF01 — Cadastro de produtos:\*\* permitir que o artesão cadastre produtos com nome, descrição, preço, foto e quantidade disponível em estoque.

# \* \*\*RF02 — Consulta do catálogo:\*\* permitir que o turista consulte o catálogo digital com nome, foto, preço e disponibilidade dos produtos.

# \* \*\*RF03 — Reserva de produtos:\*\* permitir que o turista reserve produtos disponíveis, informando seus dados de contato e a quantidade desejada.

# \* \*\*RF04 — Controle de estoque:\*\* permitir que o artesão consulte e atualize a quantidade de produtos em estoque após vendas ou reservas.

# 

# \## Requisitos Não Funcionais

# 

# \* \*\*RNF01 — Desempenho:\*\* as principais páginas do sistema, incluindo o catálogo, devem carregar em até 3 segundos em uma conexão adequada.

# \* \*\*RNF02 — Segurança:\*\* os dados pessoais dos usuários devem ser protegidos e as funções administrativas devem ser acessíveis somente por usuários autorizados.

# \* \*\*RNF03 — Usabilidade:\*\* o sistema deve possuir navegação simples e intuitiva e funcionar adequadamente em smartphones, tablets e computadores.

# 

# \## Tecnologias Planejadas

# 

# \* \*\*HTML5\*\* — estrutura das páginas.

# \* \*\*CSS3\*\* — estilização e responsividade.

# \* \*\*JavaScript\*\* — funcionalidades e interações da aplicação.

# \* \*\*Git\*\* — controle de versão.

# \* \*\*GitHub\*\* — hospedagem do código, Issues e Pull Requests.

# 

# \## Objetivo

# 

# Criar uma solução digital que facilite a divulgação dos produtos, permita reservas antecipadas e auxilie no controle de estoque da associação de produtores e artesãos locais.
